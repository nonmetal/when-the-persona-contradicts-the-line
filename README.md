# When the Persona Contradicts the Line

Audio samples for the paper *When the Persona Contradicts the Line: Diagnosing
Plan-to-Synthesis Failures in Chain-of-Thought TTS* (Joonyong Park and Jerry Li,
[arXiv:2610.35008](https://arxiv.org/abs/2610.35008)).

Page: https://nonmetal.github.io/when-the-persona-contradicts-the-line/
